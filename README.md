# FoodMap

**FoodMap** — це вебсервіс для пошуку кафе та ресторанів Києва за конкретними стравами. Проєкт створено для того, щоб пошук починався з бажаної страви, а не з назви ресторану, що дозволяє швидко знаходити заклади з урахуванням гастрономічних вподобань та місцезнаходження.

## Структура проєкту
* `css/` — директорія для каскадних таблиць стилів (візуальне оформлення).
* `images/` — директорія для графічних ресурсів (логотип, фотографії закладів).
* `js/` — директорія для майбутніх JavaScript-скриптів.
* `index.html` — головна сторінка з формою пошуку за стравами та районом.
* `search.html` — результати пошуку з панеллю фільтрації та сортування.
* `restaurant.html` — сторінка конкретного закладу з детальним меню та цінами.
* `about.html` — інформація про мету створення та місію проєкту.
* `contacts.html` — контактні дані команди та форма зворотного зв'язку.
* `README.md` — опис репозиторію.
