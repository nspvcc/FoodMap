# FoodMap

Вебсервіс для пошуку кафе та ресторанів Києва за конкретними стравами.
Слоган: «Знайди місце, де є саме те, що хочеться з'їсти».

**Виконали:** студентки групи КІ-42 — Малащенко Яна Анатоліївна, Петрашевич Анастасія Олегівна.
**Дисципліна:** Веборієнтовна розробка програмного забезпечення.

## Сторінки

| Файл | Призначення |
|------|-------------|
| `index.html` | Головна, форма пошуку страви та району |
| `search.html` | Результати пошуку з фільтрами |

## Застосовані технології (лабораторна робота 3)

- **Зовнішні CSS-файли** — стилі розділено на `base`, `layout`, `components`, `responsive` і об'єднано в `style.css` директивою `@import`.
- **CSS-змінні (`:root`)** — кольори й шрифти з брендбуку: `#F97316`, `#C2410C`, `#EF4444`, фон `#FFF7ED`, текст `#1F2937`, шрифт Inter (400/600/700).
- **Flexbox** — шапка, навігація, картки меню, «липкий» футер.
- **CSS Grid** — сітка результатів пошуку, колонки «фільтри + список», сторінка закладу, форми, контакти.
- **Медіазапити (`@media`, mobile first)** — точки зламу 768px і 1024px; на смартфонах таблиця адмін-панелі перетворюється на картки.
- **Бургер-меню** — кнопка, `menu.js`, атрибути `aria-expanded`/`aria-controls`; без JavaScript меню залишається доступним.
- **Форми й валідація** — HTML5-атрибути (`required`, `type="email"`, `minlength`, `min`, `max`), стилі `:invalid`, повідомлення про помилки через `validation.js`.
- **Доступність** — видимий фокус, `aria-current` для поточної сторінки, `prefers-reduced-motion`.
- **Препроцесори** — не використовувались.

## Кросбраузерність

- Автоматично перевірено в рушії Chromium (Chrome, Edge): відсутність горизонтального прокручування на 375, 768 і 1280 px, робота бургер-меню та валідації форм.
- Для Safari та Firefox у `base.css` додано виправлення: скидання `appearance` для кнопок і полів, власна стрілка `select`, `::-moz-focus-inner`, `-webkit-text-size-adjust`.
- Результати ручної перевірки у Firefox, Edge і Safari наведено у звіті (таблиця кросбраузерності).

## Пошук і фільтри
Сторінка `search.html` читає параметри `dish` і `location` з адресного рядка.
Фільтри за ціновим рівнем та мінімальним рейтингом застосовуються кнопкою
«Застосувати фільтри»; «Скинути фільтри» повертає початкові значення.
Дані закладів у цій навчальній версії є демонстраційними, а не актуальною
базою ресторанів або підтвердженими пропозиціями закладів.


У пошуку реалізовано демонстраційне меню страв із ціною для кожної страви окремо. Пошук за назвою показує ціну саме знайденої страви; бюджетний фільтр застосовується до її ціни. Дані меню та ціни є навчальними прикладами, а не актуальними даними закладів.


### Сторінки закладів
Кожна картка пошуку відкриває окремий заклад через параметр `restaurant.html?id=...`. Дані меню на сторінці закладу та в картці пошуку узгоджені через однакові демонстраційні набори. Для Pervak у меню немає піци, тому цей заклад не повинен з'являтися за запитом «борщ, піца». Усі ціни та меню в навчальному прототипі демонстраційні, не є підтвердженими актуальними даними ресторанів.
