# FoodMap

Навчальний вебпроєкт: сервіс для зручного пошуку закладів харчування та конкретних страв у місті. 


**Виконали:** студенти групи КІ-42, Петрашевич А.О., Малащенко Я.А

## Архітектура проєкту

```text
/FoodMap
├── /css
├── /images
├── /js
├── index.html
├── search.html
├── restaurant.html
├── about.html
├── contacts.html
├── admin.html
├── login.html
└── README.md
```

Директорії `/css`, `/images` та `/js` підготовлені для подальшого стилізування проєкту та написання логіки згідно зі стандартами веброзробки.

## Опис HTML-сторінок

* `index.html` — Головна сторінка з інтерактивною формою пошуку закладу.
* `search.html` — Результати пошуку (виведення списку знайдених ресторанів).
* `restaurant.html` — Детальна сторінка конкретного закладу з меню, картою та секцією відгуків.
* `about.html` — Інформація про концепцію проєкту.
* `contacts.html` — Зворотний зв'язок та контактні дані.
* `admin.html` — Інтерфейс панелі адміністратора для керування контентом.
* `login.html` — Сторінка авторизації для входу в систему керування.

## Використані технології

Проєкт базується на чистому **HTML5**. Для забезпечення правильної індексації та доступності застосовано сучасну семантичну розмітку (теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`). Також реалізовано інтерактивні вебформи та таблиці.

HTML-код усіх розроблених сторінок успішно пройшов перевірку на відсутність помилок за допомогою офіційного сервісу [W3C Markup Validation Service](https://validator.w3.org/).
