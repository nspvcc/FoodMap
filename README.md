# FoodMap

Вебсервіс для пошуку кафе та ресторанів Києва за конкретними стравами.

**Слоган:** «Знайди місце, де є саме те, що хочеться з'їсти».

**Виконали:** студентки групи КІ-42 — Малащенко Яна Анатоліївна, Петрашевич Анастасія Олегівна.  
**Дисципліна:** Веборієнтовна розробка програмного забезпечення.

## Використані технології та реалізовані можливості

- **Зовнішні CSS-файли.** Стилі розділено на окремі файли `base.css`, `components.css`, `layout.css` і `responsive.css`. Головний файл `style.css` підключає їх за допомогою `@import`.
- **CSS-змінні.** Для оформлення використано кольори брендбуку: `#F97316`, `#C2410C`, `#EF4444`, фон `#FFF7ED`, колір тексту `#1F2937`, а також шрифт Inter.
- **Flexbox.** Використовується для побудови окремих елементів інтерфейсу, зокрема шапки та навігації.
- **CSS Grid.** Використовується для сіток карток, розташування фільтрів і вмісту сторінок.
- **Адаптивна верстка.** Медіазапити забезпечують відображення сторінок на смартфонах, планшетах і комп'ютерах.
- **Бургер-меню.** Для мобільної навігації використовується JavaScript-файл `menu.js`.
- **Форми та валідація.** Застосовано HTML5-атрибути перевірки введення та JavaScript-файл `validation.js` для обробки повідомлень про помилки.
- **Пошук.** Файл `search.js` обробляє пошукові параметри та фільтри на сторінці результатів.
- **Сторінки закладів.** Файл `restaurant.js` відображає дані вибраного закладу відповідно до параметра в адресному рядку.
- **Доступність.** Передбачено видимий стан фокусу та ARIA-атрибути для елементів інтерфейсу.
- **Препроцесори CSS.** У проєкті не використовуються.

## Перевірка адаптивності та функціональності

Під час ручної перевірки в Google Chrome перевірено відображення сторінок на ширинах 375, 768 і 1280 px, роботу мобільного меню та перевірку полів форми зворотного зв'язку.

Повноцінне тестування в Mozilla Firefox, Microsoft Edge та Safari окремо не підтверджено. Тому сумісність із цими браузерами потребує додаткової перевірки.

## Пошук і фільтри

Сторінка `search.html` використовує параметри `dish` і `location` з адресного рядка. Фільтри за ціновим рівнем та мінімальним рейтингом застосовуються кнопкою «Застосувати фільтри». Кнопка «Скинути фільтри» повертає початкові значення.

У навчальній версії реалізовано демонстраційне меню страв із цінами. Пошук за назвою показує ціну знайденої страви, а бюджетний фільтр застосовується до її ціни. Дані закладів, меню та ціни є навчальними прикладами, а не актуальною базою ресторанів чи підтвердженими пропозиціями закладів.

## Сторінки закладів

Кожна картка результатів пошуку відкриває відповідний заклад через параметр `restaurant.html?id=...`. Дані меню на сторінці закладу та в картці пошуку узгоджені між собою в межах демонстраційного набору. Для Pervak у демонстраційному меню немає піци, тому цей заклад не повинен відображатися за запитом «борщ, піца».
